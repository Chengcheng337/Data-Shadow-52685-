## General Information

Data Shadow is an interactive creative coding prototype exploring how
everyday online activities can create a persistent digital profile.

Users can select activities such as watching videos, shopping online,
using navigation and posting photos. Each activity adds simulated data
points and coloured particles around a central figure.

The project aims to make invisible data collection visible. It uses
simulated information and does not collect real personal data.

- JavaScript
- p5.js 2.3.3

- GitHub

## Features

- Four interactive activity buttons
- Simulated data score
- Randomly coloured data particles
- A central figure that grows with the data score
- Changing platform inference messages
- Hover effects
- Reset button

## Setup

No installation is required to view the online version.

To run the downloaded project locally:

1. Download the repository files.
2. Keep `index.html`, `sketch.js` and `style.css` in the same folder.
3. Open `index.html` in a web browser.

An internet connection may be required to load the p5.js library.

## Usage

1. Open the live prototype.
2. Click one of the four activity buttons.
3. Observe the data score, particles and inference message.
4. Repeat different activities to build a larger data shadow.
5. Click **Reset experience** to return to the beginning.

## Project Status

The prototype is complete.

The current version demonstrates the main concept through simulated
interactions. It does not collect or store real user information.
